ABOUT THE PROJECT

Teknologi untuk memahami kondisi mesin.

SmartBearing adalah proyek pembelajaran implementasi supervised dan unsupervised learning menggunakan dataset bearing CWRU.

01 / DATASET

Case Western Reserve University

Dataset sinyal getaran bearing dari Case Western Reserve University, biasa digunakan dalam riset diagnosis fault bearing. Untuk proyek ini, data mentah perlu diolah menjadi fitur numerik sebelum prediksi.

Situs resmi CWRU ↗
02 / METHODOLOGY

Random Forest + K-Means

Random Forest untuk klasifikasi jenis kerusakan dengan label, sedangkan K-Means untuk menemukan cluster berdasarkan kemiripan fitur tanpa label sebagai input training.

03 / TECHNOLOGY

Python + Flask

Backend menggunakan Flask dan scikit-learn/joblib; frontend menggunakan HTML, CSS, JavaScript serta grafik Canvas tanpa library grafik eksternal.

04 / LIMITATIONS

Prototipe edukasi

Hasil analisis bukan diagnosis mesin industri tersertifikasi, tidak menggunakan sensor live, dan bergantung pada representativitas dataset serta pipeline yang dilatih kelompok.
